# Amazon Product Dataset EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on an Amazon Product Dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data Cleaning
- Duplicate Handling
- Price Analysis
- Discount Analysis
- Rating Analysis
- Feature Engineering
- Category Analysis
- Product Analysis
- Review Analysis
- Outlier Detection
- Correlation Analysis
- Data Visualization
- Business Insights
