# Amazon Product Dataset Exploratory Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis (EDA) on an Amazon Product Dataset using Python. The objective is to analyze product pricing, discounts, ratings, reviews, and category trends to uncover meaningful insights and patterns.

The project demonstrates practical data analysis skills using Pandas, NumPy, Matplotlib, and Seaborn.

---

## Objectives

- Understand the structure of the dataset
- Perform data cleaning and preprocessing
- Analyze product prices and discounts
- Explore customer ratings and reviews
- Identify top-performing product categories
- Generate meaningful business insights
- Create visualizations for better understanding

---

## Dataset Information

The dataset contains information about Amazon products, including:

- Product ID
- Product Name
- Category
- Actual Price
- Discounted Price
- Discount Percentage
- Rating
- Rating Count
- Review Content
